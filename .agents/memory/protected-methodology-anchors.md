---
name: Protected methodology anchors
description: Preserves the approval boundary around Cognirise's two canonical methodology frameworks.
---

IDAO and the Agent Authority Model are read-only canonical frameworks unless the user explicitly approves a change to them.

**Why:** Supporting methodology work must explain where it enters or updates IDAO and where consequential handovers invoke Agent Authority without silently changing either approved framework.

**How to apply:** Reference and link the approved public logic from portfolio and supporting-method pages. If a desired implementation would alter either framework's page, stage logic, calculation, diagram, imagery, interaction, CMS behavior, or tests, stop and request approval.
