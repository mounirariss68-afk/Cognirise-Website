---
name: CMS publication boundaries
description: Security boundary between mutable editorial drafts and public CMS delivery.
---

Public visibility and media access must be derived from the exact approved revision selected by a published market edition. Document-level references that drafts can replace are not public-authorization evidence.

**Why:** A draft saved after publication can reference a private asset. If public media access trusts the document’s latest reference set, that private draft asset becomes reachable before approval.

**How to apply:** Use the same all-content visibility rule for public lists, details, sitemaps, and media. Resolve media IDs from the selected approved revision, and test that draft-only assets remain unavailable.
