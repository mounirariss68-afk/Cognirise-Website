---
name: Cognirise Pulse direction
description: The approved visual and interaction direction for future Cognirise brand work.
---

Use Cognirise Pulse as the shared design language: an off-white architectural canvas, deep navy structure, violet–magenta–coral directional energy, Comfortaa display type, Inter body type, cinematic original imagery, angular crops, and editorial asymmetry. Motion should use image reveals, directional signals and spatial shifts rather than generic technical motifs. Primary CTAs use one continuous navy or inverse surface with an integrated arrow and an always-visible violet–magenta–coral Signal Rail; never use a detached or inset white arrow tile. Domain content should become bespoke spatial representations—not pale card grids, empty numbered steppers or repeated accordion rows.

**Why:** The user approved Cognirise Pulse as the creative standard, then explicitly rejected the inset-arrow CTA and later card-grid, thin-stepper and grey-box regressions as materially below that standard.

**How to apply:** Use this direction across Cognirise website pages, presentations, campaign assets and related brand materials unless the user explicitly asks for a new visual direction. Translate each content model into its own clear spatial composition.
