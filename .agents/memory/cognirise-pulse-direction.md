---
name: Cognirise Pulse direction
description: The approved visual and interaction direction for future Cognirise brand work.
---

Use Cognirise Pulse as the shared design language: an off-white architectural canvas, deep navy structure, violet–magenta–coral directional energy, Comfortaa display type, Inter body type, cinematic original imagery, angular crops, and editorial asymmetry. Motion should use image reveals and spatial shifts rather than orbiting dots or generic technical motifs. Primary CTAs use a navy body with an inset contrasting arrow tile and a gradient/offset hover transition.

**Why:** The user rejected earlier directions as bland and approved Cognirise Pulse as “almost perfect”; future deliverables should remain visually distinctive and recognizably part of this system.

**How to apply:** Use this direction across Cognirise website pages, presentations, campaign assets, and related brand materials unless the user explicitly asks for a new visual direction.
