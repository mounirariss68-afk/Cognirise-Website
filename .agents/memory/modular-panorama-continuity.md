---
name: Modular panorama continuity
description: How to preserve exact joins across independently reusable Pulse journey modules.
---

Any modular Pulse journey intended to assemble as a panorama must be created as one connected master composition first, then divided only through shared platform or conduit sections. Preserve the source segment widths proportionally and do not translate or scale individual modules in the resting assembled state. If the user asks for expanding panels, reveal each stop's own clipped view of the same master over an intact continuous image rather than resizing the single background and calling the surrounding highlight an image expansion.

**Why:** Matching themes, lighting, and a separate spine are not enough to make independently generated scenes feel connected. Exact physical joins require shared source pixels, and per-module emphasis transforms visibly pull those joins apart. The user specifically observed that highlighting a region of one unchanged image did not deliver the requested image expansion.

**How to apply:** Use one camera, baseline, lighting setup, platform, and signal route across the master. Split at intentional connector-only boundaries and verify that the resting image joins exactly. For hover expansion, keep the continuous underlay in place and let the active stop's separately cropped overlay grow; inspect actual pointer/focus behavior, not only the resting screenshot.
