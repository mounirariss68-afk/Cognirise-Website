# CMS field coverage inventory

This is the W03 field inventory for the ten governed document kinds. It is a
source-level contract check, not a claim that every public route has been
verified in a deployed environment. The structured registry used by the admin
editor lives in
`artifacts/cognirise-admin/src/pages/documents/field-coverage.ts`.

## Consumer classifications

- **Public detail** — confirmed in the public document or industry detail
  presentation.
- **Public card** — confirmed in a public listing/card presentation.
- **Public detail and card** — confirmed on both of those public surfaces.
- **Public metadata** — confirmed in public route metadata, not body copy.
- **Preview only** — editorial/governance evidence or legacy compatibility that
  is inspectable in the editor/preview but is not asserted as public copy.
- **Internal** — an authoring, routing, eligibility, workflow, or presentation
  discriminator. It may affect which public presentation is selected, but is
  not itself public prose.
- **Schema only** — the runtime contract persists the value, but no confirmed
  public consumer exists. The value is preserved and is not replaced with a
  decorative control.
- **Derived** — supplied by the runtime contract or publication state rather
  than authored as content.

## Per-kind coverage

The detailed paths, editor location, draft behaviour, publication requirement,
consumer classification, and read-only rationale are kept in the typed
registry so tests can verify all ten kinds without parsing this document.
The standalone Guardrails template is revision-shaped rather than a fixed
generic form, so its exact indexed paths are generated by
`guardrailsRevisionInventory` in
`artifacts/cognirise-admin/src/pages/documents/guardrails-editor-inventory.ts`.

## Control decisions

- Rich content uses structured block controls for paragraphs, H2/H3,
  bulleted/numbered lists, and quotations with optional attribution. Textareas
  edit one block or list item at a time, so newlines, semicolons and punctuation
  never act as a parser delimiter.
- Unsupported legacy rich blocks are shown as read-only JSON with an explicit
  remove action. They remain in the value on ordinary edits.
- `relatedIds` and publication `platformIds` use a searchable governed-record
  picker. Selected references not returned by the current query remain visible
  and pinned until an editor explicitly removes them.
- Case-study `relatedIndustries` uses a constrained multi-select. Unknown
  stored enum values remain visible until explicitly removed.
- CTA and service destinations accept only internal paths or HTTP(S) links.
  Internal paths are flagged for governed-route review; draft saving never
  depends on an external site responding.
- Existing industry and landing specialist fields remain in their existing
  workspaces. This inventory does not authorize a content rewrite, migration,
  publication, or broad reconciliation.

## Verification boundary

`field-coverage.test.ts` is a source-level inventory test. It checks all ten
kind keys, one disposition per listed specialist leaf, and representative
Education, Banking, Public Sector, Guardrails, methodology-editorial, and
site-configuration wildcard paths. For the two supported standalone
Guardrails revisions — `guardrails-legacy-v1` and `set-prove-hold-v1` — it
builds exact `content.*` inventory entries from their canonical fixtures and
asserts that the editable entries exactly equal the paths rendered by
`guardrailsEditableTextPaths`. Structural IDs, enum-backed placement values,
and fixed destinations remain explicit internal/read-only entries; shared
media, source, relationship, and governance wrappers remain in the common
registry. It does **not** execute a browser, a
deployed public route, or a preview session.

The inventory was cross-read against `ContentEditor` path wrappers and the
website's public presentation/preview source. A path marked **internal** or
**schema only** must not be moved into ordinary public-writing controls merely
to improve a count: it needs either a confirmed public renderer or a narrowly
scoped binding decision that preserves the stored field. In particular,
case-study summary/card eligibility remains driven by controlled disclosure
and evidence state; the registry does not claim that internal classifications
are public card copy.
