# Core Values and Contact editorial handover

The owner-approved Core Values page is available in the current public launch.
Its compiled template is not a CMS publication. The generated landing inventory
contains its complete editorial slots and portrait migration references.

To move it into governed publishing:

1. Import/reconcile the `core-values` landing inventory entry using the existing
   landing migration process. Resolve both portrait references to approved,
   durable media; an unresolved migration reference is not publishable media.
2. Review the complete UAE English edition through its protected preview.
   Verify the founders’ letter, nine layers, four expectations, both portraits,
   Team and Contact destinations, and SEO.
3. Publish through normal authorized review and release procedures. Do not
   rewrite an old release or publish unrelated drafts. Once released, the public
   route uses that immutable edition instead of its compiled baseline.

without an added street address or phone. London and Amsterdam retain their
confirmed corrections. Other offices and supplied phone numbers are retained.

Editors should carry these corrections into the appropriate office editions
through ordinary draft/review/publication. The support mailbox remains

insertion, corrected addresses, or new decorative Contact hero.
